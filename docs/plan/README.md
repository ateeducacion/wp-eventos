# Planes de implementación

Planes orientados a PRs para aterrizar SDD/REQ sin implementar todo de un
golpe.

| ID | Título | Estado |
|----|--------|--------|
| [PLAN-0001](PLAN-0001-implantacion-por-fases.md) | Implantación por fases del aplicativo de eventos | Propuesta |
| [PLAN-0002](PLAN-0002-continuar-el-diseno.md) | Continuar el diseño: dónde se ha quedado el trabajo y cómo seguir | Propuesta |

El PLAN-0002 no es una fase: es el **documento de continuación** del
2026-09-13. Dice dónde está cada cosa, con qué cifras se cerró el día —medidas,
no copiadas—, qué queda encolado y en qué orden, y sobre todo **las cuatro
preguntas que necesitan a una persona** para poder seguir. Se lee entero antes
de retomar el trabajo.

Los pendientes vigentes se mantienen en
[SDD-0002](../sdd/SDD-0002-arquitectura-de-reemplazo.md), no en este plan: el
plan dice en qué orden se hacen las cosas, el SDD dice qué queda por hacer.
